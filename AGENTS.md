# Community source maintenance

- Follow the human request. Do not push, deploy or publish without explicit authorization.
- Preserve LICENSE.md, NOTICE.txt and component attribution.
- Read README.md and docs/ASSETS.md before proposing a build: external VRM and Humanoid motion assets are not distributed here.
- Never add local models, music packs, secrets, personal logs or runtime data. Keep new assets private until redistribution provenance is known.
- Keep changes focused and validate the affected code. A Node test pass is not a Unity/player verification.
- Record missing environment prerequisites honestly; do not claim a public build based on an older installed binary.
- Do not weaken permissions or enable Full access on behalf of a user to avoid approval prompts.
